# 首版介面方向

日期：2026 年 10 月 2 日。首版聚焦個人記帳的日常操作：快速增加明細、確認金額、辨識保存狀態。

## 視覺計畫

- 色彩：紙白 `#FFFFFF`、霧灰 `#F4F7FA`、墨藍 `#263244`、帳簿藍 `#3D65D5`、收入綠 `#18826C`、支出棕 `#B45947`。
- 字體：數字與拉丁字使用 Manrope；繁體中文使用裝置的 PingFang TC／Microsoft JhengHei。金額採等寬數字，文字左對齊、金額右對齊。
- 桌面：固定窄側欄、頁面標題與同步狀態、餘額摘要、連續的交易清單；新增紀錄採獨立編輯面板。
- 手機：縮成底部導覽，交易明細採單欄、主要提交動作清楚可見；360 px 可完整操作。
- 特徵：將「一張紀錄可有多行」呈現為帳簿明細與底部合計，讓行與總額的關係直接可見。空帳本提供建立帳戶入口，不填入虛構財務數字。

```text
側欄 | 標題                    同步狀態
     | 帳戶餘額／本月收支
     | 日期分組的紀錄          帳戶摘要
     | 分類、名稱          金額
```

## 計畫檢視

採日常帳簿的明細排列，不以相同圓角卡片包住每個控制項。以一個藍色主動作建立層級，避免裝飾性漸層與金融宣傳圖。未連線畫面說明個人 Drive 的資料歸屬；草稿與正式餘額在視覺及資料模型上都分開。

所有按鈕須有實際動作；尚未實作的信用帳單、回饋或分期不呈現為已可使用。鍵盤焦點、表單標籤、錯誤訊息、減少動態效果及手機溢位都納入瀏覽器檢查。

## 實作後畫面檢查

2026-10-02 以 Chrome 擷取桌面 1440 × 1000 與手機 360 × 800 檢視。帳戶總額、單筆摘要與明細金額的層級清楚；手機編輯視窗可捲動，欄位與金額無水平溢位。PrimeVue 重大版本的商業授權提示已透過採用 MIT 版本移除，測試另外檢查不再出現。Google OAuth 的真實彈窗與行動瀏覽器鍵盤仍待實機驗收。
