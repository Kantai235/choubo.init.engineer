## 實作結構

```text
src/domain/          資料 schema、完整分類／幣種種子、十進位計算、操作投影
src/application/     提交與草稿工作階段；不依賴 Vue
src/infrastructure/  GIS、Drive REST、protected localStorage、下載
src/stores/          Pinia 介面狀態、session／連線與前景同步
src/features/        總覽、帳戶、紀錄、草稿與待處理、設定
src/components/      帳戶與多明細編輯、清單、圖示、連線引導
src/styles/          SCSS 共用樣式及響應式布局
```

使用 Vue 3、TypeScript 5.9、Vite 8、Pinia、Vue Router、SCSS、PrimeVue 4、Zod、Decimal.js、Luxon、Vitest、Playwright。準確版本以 `package.json` 與 `pnpm-lock.yaml` 為準。

PrimeVue 5／主題 3 在實測顯示商業授權提示，因此本版固定使用套件中標明 MIT 的 PrimeVue 4.5.5／主題 2.0.3。畫面使用自行定義的 SCSS、帳簿明細排列與對話框；沒有加入付費 UI 授權金鑰。

## Drive 提交設計

```text
My Drive / Choubo 記帳資料 /
  books / 我的帳本 /
    manifest.json
    operations /  每個不可變操作一個 JSON
    drafts /      每個草稿版本一個 JSON
    snapshots /   預留，尚未生成
    backups /     預留，尚未生成
  assets /        預留，尚未上傳圖片
  preferences /   預留，尚未同步偏好
```

提交前先核對資料夾與 manifest、拉取雲端、驗證帳戶版本與紀錄，再保存 protected pending 操作。檔案採預先產生的 Drive ID，本機記住建立任務；回應不明時查回同一 ID，不能重新產生 ID 後當成另一筆付款。使用 multipart 上傳 metadata 與 JSON，完成後再讀 metadata／content 比對。[Drive 上傳文件](https://developers.google.com/workspace/drive/api/guides/manage-uploads)

草稿使用版本／父版本圖。未同步的連續本機編輯維持單一待送版本；上傳中再編輯會保留父關係。並發草稿可在 UI 明確選擇版本；不同內容的正式操作衝突則保留並暫停受影響紀錄，不用最後修改時間決定帳務勝負。

確認 Drive 寫入且本次讀回無已知衝突才更新正式餘額；若之後同步發現並發分支，仍可能轉為待核對。Drive 不提供這個應用需要的跨檔案交易鎖，本機 Web Locks 只能協調同來源分頁，不能當成跨裝置排他鎖。

開站授權、回到前景、恢復網路、提交前及前景每 60 秒拉取變更；草稿編輯先本機保存，再延遲非同步上傳。關站不執行。授權過期暫停提交；失敗 pending 保留，在草稿頁明確查回／重試，不在背景偷偷再次記帳。待確認的交易內容鎖定，可複製成新草稿，但不能直接刪除後宣稱已取消。

localStorage 快取上限約 1 MiB；超出可重建快取上限便僅從記憶體／Drive 使用。容量失敗只清快取再試，保護草稿及 pending；仍失敗時顯示錯誤並提供草稿下載。此數字是工程快取策略，並非瀏覽器保證容量。

## 2026-10-02：首次 Drive 初始化修正

首次使用時，舊流程在建立專用資料夾之前呼叫 `files.get(root)`，將根目錄 metadata 可讀視為前提；在 `drive.file` 權限下可能先得到 404。瀏覽器模擬原本錯誤地允許讀取 root，未覆蓋使用者回報的情境。將模擬改為 root metadata 回傳 404 後，已重現連接失敗。

修正改以 `root` 別名查找／建立 Choubo 專用資料夾，再從該資料夾的查詢結果保存實際父 ID。建立確認以根目錄成員查詢驗證，不能將回傳的真實父 ID 與字串 `root` 直接比較；後續依保存的實際父 ID 偵測資料夾移動。權限維持 `drive.file`，不擴大成整個 Drive。依據：[Google 資料夾與 root 別名](https://developers.google.com/workspace/drive/api/guides/folder)、[權限範圍](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)。

新增 2 項 REST 單元測試與 3 項瀏覽器測試：root 別名與真實父 ID、錯誤位置拒絕、首次建立與重新探索不重複建帳、既有 manifest 遺失不建立空白替代、已建立資料夾移動後停止連接。全部瀏覽器案例改用不可讀 root 的模擬。Playwright 使用獨立 4175 埠且清空 Client ID 環境設定，避免沿用本機開發伺服器或真實 OAuth 設定。

本輪本機驗證：39 項單元／契約、10 項瀏覽器情境通過；lint、型別與 production build 通過。修正提交 `fb5a1dc` 的 [GitHub Actions](https://github.com/Kantai235/choubo.init.engineer/actions/runs/36920540195) 也全數通過並已部署。正式 Chrome 已確認載入該版 assets；測試帳號完成真實 Google 授權後，首次帳本初始化／同步成功，畫面顯示「已連接 Google Drive」。本次只驗證真實資料夾／manifest 建立及同步，未新增測試財務紀錄。

## 明確限制與下一階段

3. **進階衝突處理**：草稿可選版本；正式帳戶／交易衝突只偵測與匯出供核對。帳戶版本變更導致 pending 停止時，尚無完整人工重基底／撤回流程。保留資料，不自動用舊設定繼續。
4. **備份與 schema**：基本 JSON 匯出不是完整資源備份，尚無還原入口；較新 schema 會拒絕載入／提交，完整唯讀與遷移介面未完成。
5. **瀏覽器與部署**：本輪 Chrome 已測，Safari、Firefox、Edge／行動實機未驗收。沒有 PWA、背景通知或真實金融串接。production bundle 仍有超過 500 kB 的建置提醒，需隨模組拆分再量測。
6. **接續實作**：先補 M0 真實連線及 M1 的 Journal／系統紀錄、應收應付／手動結清、自訂分類與幣種，再做 M2 復原；最後依原規劃進入 M3 信用／分期及 M4 回饋／自動儲值。原始需求未刪減。

## 2026-10-02：分頁授權恢復

對應需求升為 v0.5，技術文件 v0.2；更新 AT36／42／60、D06、設定／隱私文案及開發指引。帳務需求不變；沒有加入後台、refresh token、Google scope 或長期靜默登入。流程與期限見 [分頁授權恢復](google-session.md)。

## 2026-10-02：純前端同帳號續接

依使用者要求在純前端架構內盡量延續使用，需求升為 v0.6、技術文件 v0.3。Google 單次 token 期限不由網站指定；本版採 Google 回傳完整 expires_in，不增加較短的網站登入期限。到期前五分鐘只顯示提示，續接由使用者明確點擊；沿用已驗證 email 的 login_hint 及空 prompt，盡量省去再次選帳號。Google 仍可要求登入／同意；不做計時器 popup 或永久背景續期。

新增「續接目前帳號」與獨立「切換帳號」。續接先核對 Google ownerId，再替換原 DriveClient 授權，保留 LedgerSession、交易明細及未保存帳戶欄位；同步不會自動正式提交未知 pending。取消或候選授權失敗時不提前刪除原未到期 token；明確切換才清除舊憑證與畫面。登出、切帳號及 Client ID 更動清除分頁授權與新設的無憑證帳號提示；epoch 防止遲到續接回應復活登入。

設定頁顯示實際授權到期時間；一般頁面、帳戶及記帳編輯器有續接提示。原「帳戶保存」按鈕補上 ready 檢查，過期時不誤送提交。更新需求、AT60、D06、隱私頁及授權技術文件。

本輪驗證：72 項單元／契約測試、33 項 Chrome 模擬 E2E、lint／型別／production build 通過。新增 14 項單元及 6 項瀏覽器案例：點擊同步呼叫 GIS、完整核發期限、提示隔離、授權替換、兩類編輯器保留、取消與候選 401、錯帳號拒絕、到期後一鍵重連、登出遲到回應、pending 不自動入帳。既有亮／暗桌面及 360px 回歸；新增暗色手機編輯器續接畫面經對比與溢位檢查。bundle 約 640 kB 的既有建置提醒仍在。
